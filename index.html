🔧 开发环境配置

前置条件

  • 已安装 IDMVS 或 MVS Runtime
  • 配置 SDK 的 include 和 lib 路径
  • 程序位数与 DLL 位数一致（x64 对应 x64）
⚠️ 程序位数必须与 DLL 位数一致！混用会导致加载失败。

核心头文件

MvCodeReaderCtrl.h 所有 SDK 函数声明（主接口）
MvCodeReaderParams.h 结构体、枚举定义
MvCodeReaderErrorDefine.h 错误码定义

GigE 网络配置

  • 启用网卡巨帧（Jumbo Frame），建议 9000+
  • 设备 IP 与 PC 网卡在同一网段
  • 建议关闭防火墙或添加端口例外

连接阶段代码

C — 枚举设备 
// 1. 枚举设备
MV_CODEREADER_DEVICE_INFO_LIST stDevList;
memset(&stDevList, 0, sizeof(stDevList));
int nRet = MV_CODEREADER_EnumDevices(&stDevList, MV_CODEREADER_GIGE_DEVICE);

// 2. 创建句柄
void* handle = NULL;
MV_CODEREADER_CreateHandle(&handle, stDevList.pDeviceInfo[0]);

// 3. 设置地域（中国大陆必须）
MV_CODEREADER_SetAreaInfoConfig(handle, 0xa80, 0x10000);

// 4. 打开设备
MV_CODEREADER_OpenDevice(handle);
💡 地域设置是必须步骤，未设置可能导致设备打开失败。

运行阶段代码

C — 参数设置与取流 
// 设置连续采集模式
MV_CODEREADER_SetEnumValue(handle, "TriggerMode", MV_CODEREADER_TRIGGER_MODE_OFF);
MV_CODEREADER_SetFloatValue(handle, "ExposureTime", 120.0f);

// 开始取流
MV_CODEREADER_StartGrabbing(handle);

// 获取一帧图像
unsigned char* pData = NULL;
MV_CODEREADER_IMAGE_OUT_INFO_EX2 stFrameInfo;
MV_CODEREADER_GetOneFrameTimeoutEx2(handle, &pData, &stFrameInfo, 1000);

释放阶段代码

C — 释放资源 
MV_CODEREADER_StopGrabbing(handle);
MV_CODEREADER_CloseDevice(handle);
MV_CODEREADER_DestroyHandle(handle);

⚙️ 参数设置

节点类型与接口映射

类型 读取 设置 典型参数
Integer GetIntValue SetIntValue AcquisitionBurstFrameCount
Float GetFloatValue SetFloatValue ExposureTime, Gain
Enumeration GetEnumValue SetEnumValue TriggerMode, TriggerSource
Boolean GetBoolValue SetBoolValue TriggerCache
String GetStringValue SetStringValue DeviceUserID
Command — SetCommandValue TriggerSoftware
⚠️ 枚举节点必须用整数值！
❌ SetEnumValue(handle, "TriggerMode", "On")
✅ SetEnumValue(handle, "TriggerMode", MV_CODEREADER_TRIGGER_MODE_ON)

模式 TriggerMode TriggerSource

软触发配置示例

C — 软触发 
MV_CODEREADER_SetEnumValue(handle, "TriggerMode", MV_CODEREADER_TRIGGER_MODE_ON);
MV_CODEREADER_SetEnumValue(handle, "TriggerSource", MV_CODEREADER_TRIGGER_SOURCE_SOFTWARE);
MV_CODEREADER_StartGrabbing(handle);
MV_CODEREADER_SetCommandValue(handle, "TriggerSoftware");
// 然后 GetOneFrameTimeoutEx2 取图

🔍 常见错误排查

现象 排查方向
枚举不到设备 网卡IP、设备IP、网线、防火墙、供电
能枚举但打不开 是否设置地域、设备被占用、IP冲突
打开成功但无图 未开始取流、触发模式错误、无触发信号
参数设置失败 节点类型不匹配、值超范围、取流状态不允许
读码结果为空 码制未开启、曝光不合适、ROI设置错误

⭐ 编程流程（重点）

连接阶段

C# — 枚举设备 
var deviceList = new MvCodeReader.MV_CODEREADER_DEVICE_INFO_LIST();
int nRet = MvCodeReader.MV_CODEREADER_EnumDevices_NET(
    ref deviceList, MvCodeReader.MV_CODEREADER_GIGE_DEVICE);

// 创建句柄（必须 Marshal.PtrToStructure）
var stDevInfo = (MvCodeReader.MV_CODEREADER_DEVICE_INFO)
    Marshal.PtrToStructure(deviceList.pDeviceInfo[0],
        typeof(MvCodeReader.MV_CODEREADER_DEVICE_INFO));

MvCodeReader device = new MvCodeReader();
nRet = device.MV_CODEREADER_CreateHandle_NET(ref stDevInfo);

// 3. 设置地域（中国大陆必须）
IntPtr handle = device.GetCameraHandle();
MV_CODEREADER_SetAreaInfoConfig(handle, 0xa80, 0x10000);

// 4. 打开设备
nRet = device.MV_CODEREADER_OpenDevice_NET();
⚠️ C# 中 SetAreaInfoConfig 需要通过 DllImport 调用，没有 _NET 后缀版本

释放阶段（try/finally）

C# — 释放资源 
finally
{
    if (device != null)
    {
        if (grabbing)  try { device.MV_CODEREADER_StopGrabbing_NET(); } catch { }
        if (opened)    try { device.MV_CODEREADER_CloseDevice_NET(); } catch { }
        if (handleOK)  try { device.MV_CODEREADER_DestroyHandle_NET(); } catch { }
    }
}
💡 C# 虽有 GC，但 SDK 句柄必须手动释放，用 try/finally 包裹。
