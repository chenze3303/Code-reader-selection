第一章：SDK 概述

MvCodeReader SDK 是海康机器人读码器的 C 语言开发套件，通过 void* 句柄操作设备。

核心头文件

头文件用途
MvCodeReaderCtrl.h所有 SDK 函数声明（主接口）
MvCodeReaderParams.h结构体、枚举定义
MvCodeReaderErrorDefine.h错误码定义

句柄规则

C
12
// 所有操作都通过 handle 进行 void* handle = NULL;
📝 注意

C 语言需额外 #include <stdbool.h>，SDK 部分接口使用 bool 类型。

第二章：开发环境

  • 已安装 IDMVS 或 MVS Runtime
  • 配置 SDK 的 include 和 lib 路径
  • 程序位数与 DLL 位数一致（x64 对应 x64）

工程配置

⚠️ 警告

程序位数必须与 DLL 位数一致！ 混用会导致加载失败。

GigE 网络配置

  • 启用网卡巨帧（Jumbo Frame），建议 9000+
  • 设备 IP 与 PC 网卡在同一网段
  • 建议关闭防火墙或添加端口例外

安全 CRT 推荐

标准函数安全替代
scanfscanf_s
fopenfopen_s
strncpystrncpy_s

C# — 回调（delegate 必须保存）
1234567891011121314
static MvCodeReader.cbOutputEx2delegate ImageCallback; // 必须保存！ public static void OnImage(IntPtr pData, IntPtr pFi, IntPtr pUser) { if (pData == IntPtr.Zero) return; var fi = (MvCodeReader.MV_CODEREADER_IMAGE_OUT_INFO_EX2) Marshal.PtrToStructure(pFi, typeof(MvCodeReader.MV_CODEREADER_IMAGE_OUT_INFO_EX2)); byte[] buf = new byte[fi.nFrameLen]; Marshal.Copy(pData, buf, 0, (int)fi.nFrameLen); } ImageCallback = new MvCodeReader.cbOutputEx2delegate(OnImage); device.MV_CODEREADER_RegisterImageCallBackEx2_NET(ImageCallback, IntPtr.Zero);
⚠️ C# 回调关键

① delegate 必须保存为字段/静态变量，否则 GC 回收后回调失效
② 回调中不要执行耗时操作
